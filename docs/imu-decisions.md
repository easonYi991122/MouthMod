# 头部视角通道：暂定实现选择

V5 规格（[E] §4–5、[Z] §6）冻结的部分：α ≈ 0.98；死区 ±3°；迟滞 2°；饱和 ±20°；`dx = kx·(roll−roll0)`，`dy = ky·(pitch−pitch0)`；k 左右和上下分开设；不积分偏航；校准时静止 3 s；回中 300 ms 后自动进入 ACTIVE；主循环 100 Hz 非阻塞。
下表列的是规格没写或交接指南明确要求「不能编造冻结值」的项目。这里给出的都只是**暂定值**，实测后要更新，并在组内确认。

| # | 项目 | 当前选择 | 依据 / 怎么改 |
|---|---|---|---|
| D1 | 死区与迟滞的组合公式 | 默认 `hmode=0`（内收）：\|e\| ≥ 3° 开始转，\|e\| < 1° 才停；可切换为 `hmode=1`（外扩）：≥ 5° 开始转，< 3° 停 | 交接指南 §b 标为待确认；两种都实现了并有测试，用测试页比较后由组内定 |
| D2 | 刚越过死区时速度是否跳变 | 默认 `vmode=0`，按规格原式 v = k·e（越过 3° 时直接从 0 跳到 3k）；可切换 `vmode=1` 斜坡式 v = k·(\|e\|−出界角)，速度从接近 0 开始 | 规格要求「小倾角慢转」，两种都满足；建议在测试页上对比手感 |
| D3 | k 的单位 | HID 计数 / 秒 / 度。按真实 dt 换算成整数增量，小数部分留到下次 | 交接指南要求「先明确 k 的时间单位」 |
| D4 | k 默认值 | kx = 40，ky = 30（暂定）。在 MC Java 100% 灵敏度（0.15°/计数）下，倾 10° 约 60°/s，倾 20° 约 120°/s | 按人调，记录在评估元数据中 |
| D5 | 静止判据 | 3 s 窗口内：每轴陀螺标准差 ≤ 1.0 dps；加速度均值的模长在 0.9–1.1 g；新样本 ≥ 250 个（104 Hz × 3 s 的 80%） | 规格没给；用实测静坐佩戴时的噪声来校正 |
| D6 | 校准失败的去向 | 回到 DISARMED，并报告原因（`fail_motion / fail_samples / fail_accel`），需要重新发起启用 | 不自动重试，免得「一直校准」掩盖问题 |
| D7 | 回中判据 | roll 和 pitch 误差都小于开始转动的角度（engage 边界），连续 300 ms | 和映射器保持一致：回中区内一定不输出 |
| D8 | IMU 超时 | 100 ms 没有新样本 → FAULT；启动宽限期同为 100 ms | 规格没给；按 104 Hz 计相当于丢了约 10 个样本 |
| D9 | α 与采样间隔 | α 按 10 ms 的标称步长换算成时间常数 τ = α·0.01/(1−α) ≈ 0.49 s，每个样本按真实 dt 混合；间隔 > 100 ms 时用加速度计重新初始化 | 不能把 HID 发送间隔当成 IMU 采样间隔 |
| D10 | 加速度计参与条件 | 模长在 0.7–1.3 g 时才用加速度计修正，否则这一步只用陀螺 | 抑制头部快速运动引入的线加速度 |
| D11 | 积压上限 | 每轴待发计数最多 ±64；端点阻塞时多出的部分丢弃 | 交接指南要求「不要积攒陈旧相机移动」 |
| D12 | IMU 配置 | ODR 104 Hz，±2 g，±245 dps，不用 FIFO；I2C 400 kHz；先查 STATUS_REG 的 XLDA 和 GDA 位，再一次读出 12 字节 | 交接指南 §f 的建议值；如果实测饱和，记录下来再改 |
| D13 | 安装方向 | 由「朝上轴 + 朝前轴」确定，24 种组合都支持，默认 `+Z/+X`。头部坐标系：x 前、y 左、z 上；roll 正 = 右耳向下，pitch 正 = 低头 | 装到头带上后实测确定，确定后写入 Config.h |
| D14 | 陀螺零偏存放 | 存头部坐标系下的值；修改安装方向会清掉零偏并停用 | 避免拿旧零偏去配新安装方向 |
| D15 | 调试版专用 | 用串口 `arm` 代替长吸启用，`ack` 代替 D6 拨动；DTR 断开即停用；HID 默认关闭；不启动看门狗 | 并入完整固件时，改为接 SafetyStateMachine 的吸气和 D6 逻辑 |
